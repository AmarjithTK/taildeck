## 2026-09-16 - finstall arm64 release (muse-spark)
- Built `app-arm64-v8a-release.apk` (21.9 MB) via `flutter build apk --release --target-platform android-arm64 --split-per-abi --no-pub` and installed to Redmi Note 12 (23027RAD4I) over Tailscale ADB `100.83.240.98:5555`: `adb install -r` → Success, version 1.0.1+2002, cold-launched via monkey.
- Environment finding: this shell bind-mounts `/` read-only, so Gradle cannot create its `.gradle` project cache inside the included build `flutter/packages/flutter_tools/gradle` (referenced by `includeBuild` in `app/android/settings.gradle.kts`). Symptom is a misleading instant failure (`IllegalStateException: The settings are not yet available for build` from Gradle 9.1.0's `ConfigurationCachePromoHandler`, masking the real EROFS). Proven by bisect: trivial `includeBuild` works, writable copy of `flutter_tools/gradle` works. Fix used: reran the identical build with `danger-full-access` sandbox (user consented via finstall request) — build then succeeded in ~345 s. No project files were modified for the build.
- Scratch under `app/.build-home/` (gradle home, probes, logs) removed after the build; release APKs live in `app/build/` (gitignored).
